# Whisper Транскрибация

Локальное приложение для расшифровки аудио и видео записей с автоматической корректировкой через LLM.

## Установка и запуск

```bash
./install.sh   # один раз
./run.sh       # каждый раз
```

После запуска откройте в браузере: **http://localhost:5001**

## Возможности

- **Транскрибация**: Whisper small (многоязычная модель)
- **Корректировка**: Ollama + gemma4:31b-cloud для вычитки и редактирования
- **Форматы**: MOV, MPEG, MP3, WAV, MP4 (до 2ГБ, до 2 часов)
- **Вывод**: Markdown (с таймкодами) и Plain Text
- **Два варианта**: сырой и исправленный текст

## Этапы обработки

1. **Whisper** — распознавание речи из аудио/видео
2. **Ollama (gemma4:31b-cloud)** — глубокая вычитка:
   - Исправление ошибок распознавания
   - Удаление слов-паразитов
   - Пунктуация
   - Структурирование по диалогам
   - Исправление IT-терминов
   - Список ключевых исправлений

## Требования

- Python 3.9+
- Ollama (запускается автоматически)
- ffmpeg (для обработки видео)
