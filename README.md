# Whisper Транскрибация

Локальное приложение для расшифровки аудио и видео записей с использованием модели Whisper.

## Установка и запуск

```bash
# 1. Установить зависимости (один раз)
./install.sh

# 2. Запустить приложение
./run.sh
```

После запуска откройте в браузере: **http://localhost:5000**

## Возможности

- Загрузка аудио (MP3, WAV, M4A) и видео (MP4, MKV, WEBM)
- Автоопределение языка
- Вывод в формате Markdown (с таймкодами) и Plain Text
- Скачивание результата в файл

## Структура проекта

```
.
├── app.py          # Flask бэкенд + Whisper
├── requirements.txt
├── install.sh     # Установка venv и зависимостей
├── run.sh          # Запуск сервера
└── static/
    └── index.html  # Веб-интерфейс
```

## Первый запуск

При первом запуске модель Whisper small будет загружена автоматически (~500MB). Это займёт некоторое время.

## Системные требования

- Python 3.9+
- ffmpeg (для обработки видео)
